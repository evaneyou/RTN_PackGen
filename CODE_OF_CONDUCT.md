# Code of Conduct

We want RTNP to be a place where people can ask questions, report problems and contribute without being
treated badly.

## What we expect

* Be respectful and assume good intent. Disagree with ideas, not with people.
* Give and accept feedback on code and docs constructively.
* Keep discussion on topic and in the open (issues and pull requests), except for security reports, which
  follow [SECURITY.md](SECURITY.md).

## What is not acceptable

* Harassment, insults, threats or personal attacks.
* Discriminatory language or behaviour.
* Publishing someone else's private information.
* Anything else that would reasonably make others feel unwelcome.

## Enforcement

The maintainer ([@evaneyou](https://github.com/evaneyou)) may edit or remove comments, close issues and pull
requests, and block people who break these rules. To report a problem, contact the maintainer through GitHub
(for sensitive cases, open a private security advisory from the repository's Security tab and mention it is
a conduct report).

This is a short, plain-language policy written for this project; it is inspired by common open-source
codes of conduct such as the Contributor Covenant.
